## Work completed

- **Baseline commit:** Committed the accumulated foundation as `ce0bebc`
  (`Wire research run foundation and frozen CLI`).
- **Source configuration:** Added catalog defaults and request overrides for
  per-type record caps, source-age limits, and required domain-route types.
  Scout and Library enforce these limits independently. Added an adapter
  builder that enables only implemented, credential-ready providers; live
  search remains opt-in.
- **Retrieval:** Replaced the coordinator's lexical-only run index with a local
  TF-IDF/lexical hybrid. It applies configured chunk size, overlap, corpus,
  chunk-count, and estimated index-size limits. Index metadata records the
  model/version, limits, run ID, and run-only retention policy. No hosted
  embedding calls are needed.
- **Final proposals:** Added a proposal draft contract and prompt. The model
  supplies narrative fields; code supplies candidate identity, rank, and
  scores. Citations must point to supplied source receipts and Library chunks.
  A finalist without cited chunks produces a coverage warning rather than an
  unsupported proposal.
- **Entry point and documentation:** The frozen-fixture CLI now returns full
  run JSON including proposals. Updated the README, design notes, task tracker,
  and focused source-code comments/docstrings.
